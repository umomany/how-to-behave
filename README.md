# لعبة «كيف أتصرّف؟»

لعبة عربية للأطفال تعرض مواقف يوميّة وتسأل: ماذا تفعل؟ لكل سؤال ثلاثة خيارات، ولكل نصّ صوت مسجّل مسبقًا.

**العب مباشرة: https://umomany.github.io/how-to-behave/**

*An Arabic behavior game for children, with pre-rendered speech for every line. Static site — no build step, no server.*

## التشغيل

افتح الرابط أعلاه من أي هاتف أو حاسوب. أو نزّل المستودع وافتح `index.html` بمتصفّح Chrome أو Firefox أو Edge؛ أبقِ مجلّد `audio` بجانب الملف دائمًا، فمنه تُقرأ الأصوات.

لا يحتاج التشغيل إنترنت (عدا الخطوط، وتعمل اللعبة بدونها). وإن تعذّر تحميل مقطع صوتي رجعت اللعبة تلقائيًا إلى نطق المتصفّح.

## عن الأصوات

- المحرّك: **edge-tts** (أصوات مايكروسوفت العصبية) بصوت `ar-SA-HamedNeural` وسرعة `-10%`.
- ٣١٢ مقطعًا، نحو ٣٧ دقيقة، ١٣٫٥ ميغابايت بصيغة mp3 (‏48kbps / 22050Hz).
- النصّ المنطوق مأخوذ من `manifest_tashkeel.json` — تشكيل يدويّ، وهو يُحدث فرقًا مسموعًا في الجمل العامّية دون الفصحى.
- كل المقاطع مضبوطة الصوت بـ `loudnorm I=-16` حتى لا يقفز مستوى الصوت بينها.

## إعادة التوليد

```
python3 -m venv .venv && .venv/bin/pip install edge-tts
sudo apt install ffmpeg
.venv/bin/python build_audio.py
```

يقرأ السكربت المانيفست ويكتب `audio/<بصمة>.mp3`. وهو **قابل للاستئناف**: يتخطّى أي ملف موجود، فإن انقطع الاتصال أعِد تشغيله ليُكمل ما نقص. لتغيير الصوت أو السرعة بدّل `VOICE` و`RATE` في أوّل الملف، واحذف `audio/*.mp3` قبل التشغيل.

## تنبيه مهمّ عند التعديل

اسم كل ملف صوتي هو بصمة **FNV-1a** لنصّه، و`index.html` يحسب البصمة نفسها في جافاسكربت (الدالة `fnv`). فإن غيّرت نصًّا تغيّرت بصمته وانقطع الصوت عنه حتى تُعيد التوليد. لا تُعِد تسمية الملفات يدويًا أبدًا.

- `audio/manifest.json` — البصمة ← النصّ بلا تشكيل.
- `manifest_tashkeel.json` — البصمة ← النصّ مشكّلًا (وهو المستعمل في التوليد).
- المفاتيح متطابقة في الملفّين.
